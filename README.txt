PERSONAL PORTFOLIO — PLAN AND HTML SCAFFOLD

Open wireframe.svg in a browser to view all three page sketches and design notes.
Open index.html in a browser to start the portfolio. Keep all files together.

FILES
index.html — Home: introduction, call to action, featured project.
projects.html — Projects / Work: introduction and two project placeholders.
about.html — About / Contact: biography, skills, and contact placeholder.
styles.css — Shared starter styling and mobile layout.
wireframe.svg — Digital wireframe with color and font choices.

DESIGN
Background #F8FAFC; surfaces #FFFFFF; text #172033; accent #1D4ED8.
Headings: Georgia, Times New Roman, serif.
Body and navigation: Arial, Helvetica, sans-serif.
At small widths, project cards stack and navigation wraps.

CUSTOMIZE
Replace bracketed content with your own information. Add actual project images
and descriptions when available. Contact information is intentionally a text
placeholder until you choose what to share publicly. No form submission or
external services are configured.

STRUCTURE
Each page has an HTML5 doctype, language, character encoding, viewport, title,
header, shared navigation, main, sections, and footer. Each page has one h1,
section h2 headings, and subordinate h3 headings. All navigation links are
relative, and the current page is marked with aria-current="page".
